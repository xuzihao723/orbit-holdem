# 约两分钟演示脚本

本地演示采用隔离候选、独立测试身份和合成房间数据。剪辑只移除等待与重复操作。

| 时间 | 场景 | 画面与字幕 |
|---|---|---|
| 00:00–00:12 | 首页 | 轨道牌桌，虚拟筹码，2–4 席 |
| 00:12–00:30 | 单人 | 选择入门电脑，开始本手，做一次合法动作并结算 |
| 00:30–00:46 | 双人 | 独立身份加入，准备后由房主开局 |
| 00:46–01:00 | 三人 | 四席容量留一空座，三位真人开局 |
| 01:00–01:20 | 四席混合 | 两个真人加两档电脑，从候场到牌桌 |
| 01:20–01:41 | 断线恢复 | 观察断开提示、恢复原席、继续操作 |
| 01:41–02:00 | 回放 | 进入历史、打开一手、逐步并跳到结算 |

另导出首页、桌面牌桌、360px 手机、边池与退款结算、历史回放五类截图。边池使用隔离固定场景时在索引注明夹具。录像和截图使用测试昵称，公开交付前逐段检查界面是否露出真实身份和令牌。
