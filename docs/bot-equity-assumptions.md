# 标准策略采样假设

W26（2026-11-01）仅完成纯内核，实时standard仍明确basic回退，工作线程在W27接入。

翻前使用完整169类项目自定启发式：13对子+78同花+78非同花，牌面10记T。全部1326组合归类、牌顺序对称。基础分沿W25；所有对子至少中等45、JTs以上同花宽牌至少45，原分≥60为强。它不是经验胜率表或GTO，翻前通过同一位置、人数、成本和合法动作框架选择。

采样仅把本人两牌与公共board作为已知，校验牌号唯一和preflop0/flop3/turn4/river5长度。未知52减已知；每样本无放回抽未弃对手两牌和剩余board。folded贡献保留、底牌不扣入已知（均匀模型的边缘化）；allIn仍有资格。真实对手牌、牌堆、烧牌均不作为输入。

模型是本人补齐min(callAmount,stack)后，其余人不新增下注并check到摊牌，不预测范围、诈唬、未来下注或跟注。真实rankShowdown与awardContributions决定每池赢家/并列/余数和未匹配退款。weightedShare只对本人有资格池按金额加权，退款不算赢池；expectedReturn平均本人实际整数payout+refund，expectedNet再减本次可付成本，不重复扣过去投入。

requestedSamples默认1000，实际completed逐样本递增；每样本检查停止，0或部分样本不会伪装1000。running mean避免大量金额累加溢出。0样本回退basic；需付费且净收益≤0时fold，免费check保留，份额≥0.65且成本≤0.25才以0.35概率尝试不超过最小下注两倍的合法bet/raise。无重开/短全押约束仍经正式adapter。

性能数据随CPU与并发变化。最终W26全量中的一项1000样本约266.8ms，原始值在w26-equity-baseline.json；不承诺150ms完成目标样本。W27须用真实单调时钟从提交起计算预算，包含排队，安全返回实际部分样本或回退。
