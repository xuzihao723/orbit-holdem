# 历史与回放

历史入口为 /history，回放入口为 /history/:handId。访问由已恢复的访客身份与持久参赛名单共同决定。历史列表按时间和手牌编号稳定分页，默认 20 条，最多 50 条。相同时间戳的记录依然有稳定顺序。

回放来自已提交事件。本人的底牌从发牌时显示，对手底牌只在已公开的摊牌事件后显示。逐帧检查筹码守恒，派奖与贡献归零在同一帧发生。手内变化是结束筹码减去本手起始筹码，额外入场筹码、离席取走和重开增发分别计入台账。退款单列，退款不计为赢池。中止手保留可见过程，最终结果和净变化为空。

服务端在返回前再次检查当前控制连接。切换身份、记录或离页时，前端丢弃过期结果并清理播放定时器。验证入口为 npm run verify:replay 和 npm run test:replay:browser。
