# 运维操作

升级：确认当前单实例与数据目录→创建并校验备份→停止旧进程→部署新构建→检查ready/HTTPS/WS→两独立身份完成一手与历史回放。没有通过恢复演练的备份不作为已验证保障。

回滚：先停止当前实例；保留当前库，再检查旧版本是否兼容新迁移。不能盲目用旧程序打开新schema；需要恢复时按backup-restore.md写入新隔离目录，不覆盖原库。

故障：ready 503先查数据库可读/磁盘空间/目录权限；保存失败的房间保持暂停，不继续发牌；worker预算回退记录原因，健康检查不能包含底牌或会话。重启后中止旧手是既定行为，已结算历史应保留。

日志只保留事件名、脱敏关联、时刻、耗时、结果。不写resumeToken、token_hash、完整牌序或原始私有帧。无真实主机、域名和Docker验证证据时，公网与容器验收保持待完成。
