# 提示音试听验收单

音频解码、声道和峰值已有自动检查。主观试听由实际听众完成并独立记录。

| 提示 | 音源 | 试听内容 |
|---|---|---|
| 发牌 | [播放](../../assets/audio/deal.mp3) | 是否短促清晰、连续开局时是否刺耳 |
| 翻牌 | [播放](../../assets/audio/flip.mp3) | 是否能与发牌区分 |
| 行动 | [播放](../../assets/audio/action.mp3) | 高频动作时音量是否适合 |
| 赢池 | [播放](../../assets/audio/win.mp3) | 是否容易辨认，是否明显盖过其余声音 |
| 入房 | [播放](../../assets/audio/join.mp3) | 是否能区分入房与普通操作 |

用手机扬声器和一套耳机各听一轮，注明候选、设备类别、音量设置、时间、结果和具体问题。再在应用设置中开启音效完成一手，切换静音确认立即停止。正式报告引用真实听众结果。
