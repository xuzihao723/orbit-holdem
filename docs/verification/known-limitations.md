# 已知限制

| 范围 | 说明 |
|---|---|
| 本地候选 | 当前验收范围为本机。镜像构建、持久卷、公网 HTTPS、跨网恢复与正式试玩需要获授权的部署目标。 |
| 参与者证据 | 已准备试玩材料。五份独立反馈和实机问题复测待实际场次。 |
| 音频 | 音量峰值及 OGG/MP3 解码可自动验证。听感与辨识度由实际听众签收。 |
| 身份 | 历史和恢复绑定访客凭据。丢失凭据后该浏览器无法恢复原身份。 |
| 重启 | 进行中的牌局会归档为中止，已结算记录保留。验证恢复用独立目标目录和数据库。 |
| 部署模型 | 首版使用单实例服务与 SQLite 持久卷。 |
| 电脑策略 | 标准电脑使用均匀未知牌假设和计算预算。200 手模拟用于发现非法动作、卡局和筹码不守恒。 |
| 弱网结论 | 180 条数据来自单机代理、固定对手时序和 10 秒观察窗口。延迟测量包含连接与身份请求。 |
