# W35 组件状态核对

开发入口为 `/?preview=states`。用生产组件显示受控状态，覆盖空座、准备、行动、弃牌、全押、离线、等待、出局、牌正背、公共槽、计时、加注权限、边池退款及回放。固定的牌值和金额只用于状态预览。

360×640、390×844、430×932、1280×720 和 1440×900 的开发浏览器检查通过。覆盖数字校验、键盘焦点、主操作高度、回放首末与播放状态，以及无水平溢出。360 和 1440 的截图已目视抽查。[浏览器证据](w35-state-assets-playwright.json) · [手机](w35-state/component-states-360.png) · [桌面](w35-state/component-states-1440.png)

浏览器红例先确认状态板入口缺失。补齐后发现 React 开发重复挂载会过早销毁播放器。调整 Hook 清理为停止计时并由订阅方解绑，复跑五视口通过。
