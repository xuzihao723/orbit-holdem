# W44 首版验收清单

按[任务看板第 10–13 节](../../../plan/04-任务看板与发布验收.md)及[原验收总表](../../../plan/四人联机德扑-详细制作规划.md)核对。本机与目标环境分开签收。

| 必需范围 | 本地证据 | 外部或人工验收 |
|---|---|---|
| 安装与启动 | 干净依赖、类型、构建、独立服务和健康探测。[命令](w44-commands.json) · [编译启动](w44-local-deploy.json) | 目标容器镜像与持久卷 |
| M01–M13 人数模式 | 2/3/4 人、两档电脑、混合、容量、单人限制、末座竞争。[发布矩阵](w44-release-playwright.json) | 真实跨网设备 |
| 规则和筹码 | 双人次序、多转双、短全押、主边池、平分、退款、守恒。[规则](w44-core.json) · [牌桌](w44-table-playwright.json) | W41 反馈与问题关闭 |
| 权威与生命周期 | 串行处理、去重和冲突、期限竞争、房主转移、退座、全离线、受控重启和 SQLite 恢复。[集成](w44-integration.json) | 目标主机重启、持久数据和隔离备份恢复 |
| 断线与隐私 | 保座、版本、恢复、旧连接接管、未参与回放拒绝、只显示获授权的牌。[集成](w44-integration.json) · [回放](w44-replay-playwright.json) · [实验](../experiments/reconnect/summary.md) | 目标地址冒烟和跨网恢复 |
| 电脑 | 观察受限、预算取消、两档操作与 200 手模拟。[模拟](w44-bot-sim.json) | 试玩观察 |
| 卡面与辅助素材 | 52 正面、双牌背、空槽、辅助资源和双格式解码。[素材](../card-assets.md) · [音频](w44-audio.json) | [五种提示音试听](audio-listening.md) |
| 视觉与操作 | 五种视口、等待者隐私、触控目标、键盘、颜色、静音、减少动效和组件状态。[状态板](w35-state.md) · [设置](w44-ui-playwright.json) | 实机键盘、横竖屏和跨设备体验 |
| 发布产物 | 扫描开发入口、固定牌序和私密材料。[产物扫描](w44-release-artifacts.json) | 目标镜像、HTTPS 地址与公开材料核验 |
| 作品与实验 | README、五类截图、视频、技术报告、原始实验数据和复算。[作品](../showcase/index.md) · [实验](../experiments/reconnect/summary.md) | W41 修复后确认正式录屏与署名 |
| 真实试玩 | [脚本和记录模板](w41.md) | 至少五份独立反馈，阻断、规则与隐私问题全部关闭 |
| 运行限制 | [已知限制](known-limitations.md) | 上线时与页面说明和实际运行结果复核 |

V3 / M5 的最终签收依赖所有必需项。公网目标、人工试听与正式试玩的空缺在发布报告中逐项保留。
