# 轨道牌桌试玩单

预计每场 15–25 分钟。由组织者提供当场地址、房间码和自己的参与者代号。使用虚拟筹码。每场最多四席，第二轮至少包含一位第一轮未参加的玩家。

## 发给参与者的文字

请用平时使用的浏览器打开试玩地址。按组织者分配的模式开桌或加入，完成准备、开局、一次行动、结算和下一手准备。遇到卡住的地方请先记下最后一次操作和界面提示，截图前遮住房间码、底牌和个人信息。

## 组织者场次

| 场次 | 参与者 | 操作与核对 |
|---|---|---|
| S01 双人 | P01、P02 | 不同网络，完成一手。P02 刷新页面，核对仍为原身份。 |
| S02 三人 | P01、P03、P04 | 四席容量保留一个空座，三人可以开局并结算。 |
| S03 四人 | P01、P02、P03、P04 | 两部手机加两套桌面浏览器环境。安排一人断网约 5 秒，恢复后检查席位、余额与当前动作。 |
| S04 混合 | P02、P05 | 加一名入门和一名标准电脑。结算后用手机进入历史，逐步查看回放。 |

至少一台手机使用蜂窝网络，另一端使用 Wi-Fi 或有线网络。实机型号记录到设备类别即可。每位参与者独立填写一份反馈，场次跨用的参与者仅计一次。

## 参与者反馈

- 代号、场次、候选版本、设备类别、浏览器及网络类别。
- 哪些步骤完成了。若无法继续，停在第几步，当时看到什么。
- 360–430px 手机上的牌值、筹码、倒计时和主要按钮是否易读。
- 用自己的话解释「加注至 100」和「本次投入 80」各表示什么。
- 是否误触，能否用键盘或触控回到操作区。
- 刷新、断网或回放时，界面如何提示。恢复后的席位和筹码是否符合预期。
- 最影响完整对局的一处问题。可附脱敏截图。

## 记录口径

把实际尝试登记到 `sessions.csv`，使用 `completed` 或 `interrupted` 标注结果。参与者身份和网络仅保留代号及类别。独立反馈归档、问题去重和复测后才能计入验收。
