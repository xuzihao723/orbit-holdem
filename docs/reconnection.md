# 身份恢复与保座

W22（2026-11-01）支持当前进程有效席位的刷新、短断线恢复；身份30天有效期与120秒席位资格分开。资格严格为now < reserveUntil，恰120秒仅恢复身份；现金移出、房主与重启归档在W23实现。

服务端先持久增加连接代数、绑定新控制，再在房间队列投影并复验当前控制。只有最终验证成功才消费保座；投影或后续存储读取失败不延长原期限。接管旧连接迟到断开不启动新保座。等待者没有本人牌和动作；恢复使用最新快照，原deadline与已提交超时动作不回滚。已settled本手定向补发脱敏结果。

客户端凭据与非秘密房间定位分开保存。恢复协调器500/1000/2000/4000/8000ms退避，最多6次；RATE_LIMITED遵守retryAfterMs，存储暂不可用也退避。手动重试可重启耗尽流程。无凭据不自动guest；expired/takenOver和主动断开不自动抢权。取消同时移除连接等待计时器与监听器。

ViewStore订阅供React使用；私有身份响应建立self participant，identityOnly/handInterrupted清旧手和动作。私有身份确认前只暂存最多12帧，确认后按当前连接/epoch/room/本人过滤，不从普通广播建立身份或epoch。不重播离线下注。ConnectionBanner在W30挂正式页。
