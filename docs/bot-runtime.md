# 标准电脑线程运行时

W27使用真实编译equity.worker.js，默认2线程、队列32、提交起150ms；配置上限4线程/32排队/1000ms，非法参数启动失败。主线程只投影、校验和提交；worker使用独立Observation、seed和单job共享取消标记，每样本检查预算/取消。部分样本按实际数量采用，0样本或故障回退basic。

提交、排队、启动均计预算；主线程超时定案一次，迟到/错误绑定/重复消息无提交权限。挂起线程取消后25ms终止，每slot最多重建2次；关闭先取消调度、等待线程终止，再关队列和数据库。展示延迟500–1500ms与真实计算预算独立。结果须复验hand/turn/version/bot/participant/deadline和队内isCurrent；只变roomVersion不会取消有效任务。

开发脚本先编译后运行dist，并同时watch编译产物；已验证修改worker触发新serverEpoch。生产Node直接加载编译JS，不依赖tsx继承。诊断回调收到冻结结果，不能改变随后执行的估计。

集成测试每次最多2文件并行：每文件可能再建线程池。未限并发时冷启动争抢导致3个预算测试失败，限制后完整341项通过；未放宽生产预算或测试超时。跨房间原始报告记录100次成功命令和100次健康查询，生产限额未改。性能数值是本机观测，不是服务承诺，见[w27响应数据](verification/w27-responsiveness.json)。
