# 轨道牌桌技术报告

## 产品范围

轨道牌桌面向 2–4 席练习和好友对局。玩家可以用两个真人开局，也可以在手间安排电脑补位。所有金额以虚拟筹码计。首版以单实例同源部署为运行模型。

## 服务端与规则

共享规则包负责牌型、位置、下注合法性、主边池和结算。短全押允许增加下注差额，重新加注权仍按完整加注幅度与本座位此前的行动计算。未被匹配的投入先退回，分池后按各池合格座位派奖。

服务端为动作权限和筹码的权威来源。房间串行执行事务，命令收据按身份和命令 ID 去重。相同 ID 与原始载荷可取回已有结果，过时版本不会改变筹码。事务提交后才发布视图。断线重连校验控制身份并应用当前版本快照，客户端按连接、房间、手号和版本拒绝旧消息。

代码入口为 `packages/poker-core/src`、`apps/server/src/game/command-handler.ts` 和 `apps/web/src/network`。规则例证见[结算](core-settlement.md)、[下注](core-betting.md)和[恢复](reconnection.md)。

## 访问边界与电脑

实时牌桌只传本人底牌和合法动作，已公开牌按牌局状态显示。历史与回放依赖参与者归属，按事件投影本人可见状态。电脑获取受限观察与合法动作，标准策略在线程预算内对未知牌采样。均匀未知牌假设影响策略解释，现有模拟覆盖合法性与稳定性。

## 验证与范围

W31–W40 的本地验收记录包括 214 项规则、412 项集成、71 项浏览器测试与 200 手电脑模拟。W43 的 180 次本机对照中，快照组 90 次均在 10 秒内恢复并继续，基线组在固定的无新消息窗口内保持旧版本。真实公网、正式试玩和人工试听分别留证。[上一批本地验收](verification/w31-w40.md) · [对照方法](experiments/reconnect/method.md) · [实验结果](experiments/reconnect/summary.md)
